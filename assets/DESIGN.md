# OLMAX visual assets

Approved direction: crimson / charcoal / off-white, road monogram, sunset vehicle photography,
three vehicle categories and a designed empty-catalog state. Approved in this task before implementation.

`logo.svg`, `logo-light.svg`, `favicon.svg`: editable SVG road mark and OLMAX wordmark.
`hero.jpg`, `cars.jpg`, `trucks.jpg`, `trailers.jpg`: illustrative images created using the built-in
image_gen tool, then JPEG encoded at quality 82 for the website. They are not actual inventory photographs.
Original generated PNG files remain in the local image generation output folder.
